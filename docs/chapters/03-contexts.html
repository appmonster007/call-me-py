One function, many lives

ident returns whatever it is given. It's called twice, with two different functions. If the analysis keeps a single summary of ident, the two calls blur together.

Each step below is a real run of the analyzer with a different max_contexts.

Doesn't a node per argument combination explode?

It could. Two things keep it small. A context records only parameters that hold tokens: square(3) and square(4) share one context, because numbers carry no functions. And max_contexts caps whatever is left. Past the cap, the analysis gets less precise; it never misses a call.
