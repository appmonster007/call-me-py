Teaching it the builtins

map(square, xs) calls square, but map is written in C. The analyzer can't read it, so stubs/ tells it what each builtin does with its arguments.

Adding a stub

A stub is a function (interp, args, site) → value, registered under the names it answers to. Bare names are builtins; dotted names are reached through imports of the modules in STUB_MODULES; methods of builtin containers go through METHOD_STUBS. This is a whole stub:

Callbacks are invoked with call(it, …, site), at the builtin's own call site.

Why is square's context x={<list@12:24>}?

Containers are collapsed: the elements of [1, 2, 3] are approximated by the list's own value. Integers carry no tokens, so only the Box is left. It looks odd and costs nothing, and for a list of functions it's exactly right: they are in the value, so map(lambda f: f(), handlers) calls every handler.
