Functions that remember

wrap(inc) and wrap(dec) both return run, and only one of them is called. To know that a(1) reaches inc and not dec, a function value has to remember where it was created.

The same tether answers nonlocal and global in the other direction: a write from an inner function is collected in State.extern and merged into the owner's environment the next time the owner is analysed.

Can tethers chain forever?

A closure made inside a closure made inside a closure… Each level nests one context inside another, and that could grow without end. Past MAX_DEPTH = 3, mk_closure drops the tether (parent=None). Lookups then take the union over every context of the enclosing function: less precise, but finite.
