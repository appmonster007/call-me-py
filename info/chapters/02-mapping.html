Mapping the program

Before it evaluates anything, the analyzer takes inventory: every function, where it lives, which names it owns, which calls it contains.

This is extract.py, one pass over Python's AST. Step through the functions, or click a line of code to jump to the function it belongs to.

Why does the analyzer need to know each function's locals in advance?

Python decides scope statically: a name assigned anywhere in a function is local to the whole function, even on lines before the assignment. So lookup must know, before running a body, whether a name is local or belongs to an enclosing function. scope_locals applies exactly that rule, honouring global and nonlocal.
